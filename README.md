# 📊 E-Commerce Sales Analysis — End-to-End SQL Project

![Sales Analysis Dashboard](sales%20analysis.png)

## 🔍 Project Overview

An end-to-end data analysis project using **SQL**, **Python**, and **Power BI** 
to analyze 9,994 retail orders across the United States. The project covers the 
full data pipeline — from raw CSV data to an interactive business dashboard.

---

## 📁 Dataset

- **Source:** Kaggle — Retail Orders Dataset
- **Records:** 9,994 rows
- **Period:** January 2022 – December 2023
- **Columns:** Order ID, Category, Sub-Category, Region, State, Ship Mode, Cost Price, List Price, Quantity, Discount

## 💡 Key Business Insights

1. **West region** generates the highest revenue at **3.47M** — 31% of total sales
2. **Technology** is the most profitable category
3. **Chairs and Phones** are the top 2 sub-categories by revenue
4. **South region** has the lowest revenue at 1.97M — opportunity for growth
5. Monthly trend shows **Q4 spike** — strong seasonal demand in Oct–Dec
